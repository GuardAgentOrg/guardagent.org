GuardAgent REST API Reference

Programmatic reference for GuardAgent's deterministic security evaluation gateway, policy store, human approvals, and tamper-proof audit ledger.

Base URL & Protocol

PORT 3000
BASE URL SPECIFICATION 
# Local Development
http://localhost:3000/api

# Production Deployment (Private VPC)
https://guardagent.your-company.internal/api

GuardAgent enforces strict JSON payloads. Every POST and PATCH request must include the Content-Type: application/json header.

POST

/api/requests/evaluate

The primary security gateway endpoint. AI agents invoke this endpoint before executing any registered tool or sensitive operation. GuardAgent evaluates declarative rules, computes risk, and returns a deterministic decision in 0.8ms.

Request Payload Schema:

Field Type Required Description
agent_id string Yes Unique identifier of registered agent (e.g. "agt-customer-support-01").
tool_name string Yes Target tool identifier (e.g. "stripe.transfers.create", "sql_query").
action_name string Yes Specific action being invoked (e.g. "process_refund", "execute_query").
parameters object No Key-value map containing the arguments passed to the tool.

Example cURL Request:

CURL // EVALUATE ACTION 
curl -X POST http://localhost:3000/api/requests/evaluate \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "agt-customer-support-01",
    "tool_name": "stripe.transfers.create",
    "action_name": "process_refund",
    "parameters": {
      "amount_usd": 1450.00,
      "account_id": "act_4412_premium"
    }
  }'

Example 200 OK Response:

JSON DECISION (0.8MS) 
{
  "request_id": "req-98f2b31a",
  "decision": "REQUIRE_APPROVAL",
  "risk_score": 65,
  "risk_level": "HIGH RISK",
  "latency_ms": 0.8,
  "evaluated_rules": [
    { "rule": "Is bot allowed to refund?", "passed": true },
    { "rule": "Is $1,450 within $500 limit?", "passed": false, "reason": "Exceeds $500 cap" },
    { "rule": "Is payment destination safe?", "passed": true }
  ],
  "rationale": "Safety Cap Triggered: $1,450.00 exceeds your $500 safety rule. Held for human signoff."
}
GET

/api/health

Returns current operational status, evaluator engine type, version, and uptime metrics.

200 OK RESPONSE 
{
  "status": "healthy",
  "version": "1.2.0",
  "evaluator_engine": "deterministic-ast",
  "uptime_seconds": 128
}

/api/agents

List all registered AI agents or enroll a new autonomous agent with a role and permissions.

RESPONSE // LIST REGISTERED BOTS 
[
  {
    "agent_id": "agt-customer-support-01",
    "name": "Customer Support Bot",
    "role": "support_agent",
    "status": "active",
    "allowed_tools": ["stripe.transfers.create", "zendesk.tickets.update"]
  },
  {
    "agent_id": "agt-lead-enrichment-02",
    "name": "Web Research Bot",
    "role": "researcher",
    "status": "active",
    "allowed_tools": ["http_fetch"]
  }
]

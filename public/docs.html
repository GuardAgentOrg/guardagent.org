GuardAgent Documentation

GuardAgent is a deterministic safety switch and compiled security gateway for autonomous AI agents. It intercepts every API, database, and system tool call in 0.8 milliseconds — blocking attacks, unauthorized funds transfers, and accidental table deletions before they touch production.

REQUEST INTERCEPTION FLOW:
🤖 AI Agent (LangChain / CrewAI) → 🛡️ GuardAgent (0.8ms Check) → 🌐 Real APIs & Live DB

What is GuardAgent?

When autonomous AI agents interact with external systems (such as Stripe payments, cloud server metadata, SQL databases, or operating system shells), granting direct, unverified access creates catastrophic risks.

Prompt injection attacks, malicious third-party web content, or unexpected model hallucinations can trick an agent into sending unauthorized wire transfers, deleting live customer databases, or leaking confidential cloud keys.

GuardAgent acts as an authoritative safety gate between the AI agent and the tools it intends to call. Before any network call is dispatched or database query is executed, GuardAgent validates the action against your declarative safety rules, computes an explainable risk score, and issues an instant decision in 0.8ms.

Key Concepts

Concept Description
Agent An enrolled AI bot or assistant identified by an agent_id with predefined permissions and allowed tools.
Tool A registered capability (e.g. stripe.transfers.create, sql_query, http_fetch) controlled by GuardAgent.
Safety Policy A declarative rule (e.g., maximum refund $500, forbidden SQL commands, whitelisted IP addresses).
Decision The instant 0.8ms deterministic outcome: ALLOW, REQUIRE APPROVAL, or BLOCK.
Human Signoff A review item dispatched to Slack or Teams requiring an operator click before releasing high-stakes actions.
Audit Ledger A cryptographic, append-only local log recording every action, parameters, decision, and timestamp.

Quick Installation

Install GuardAgent with a single terminal command in Python or JavaScript:

TERMINAL INSTALLATION:
pip install guardagent # Python SDK
npm install @guardagent/sdk # Node.js / TypeScript

Quickstart & Local Setup Guide

Get an authoritative GuardAgent AI security gateway running locally in under five minutes with zero external database dependencies.

Workstation Prerequisites NO DOCKER REQUIRED

Ensure you have the following installed on your machine:

Node.js v18.0.0+ (LTS) npm v9.0.0+ Git 2.0+
01

Clone the Repository

Clone the open-source repository from GitHub and navigate into the project directory:

BASH / TERMINAL 
git clone https://github.com/guardagent/guardagent.git
cd guardagent
02

Install Runtime Dependencies

Install the lightweight core gateway dependencies (Express, CORS, and Dotenv):

NPM 
npm install
03

Configure Environment Variables

Duplicate the template configuration file to initialize your local .env file:

SHELL 
cp .env.example .env

Zero-Config Local Mode: If you leave the keys empty in .env, GuardAgent automatically runs in Local Verified Memory Store Mode. It pre-populates seed agents, declarative safety policies, and historical audit logs for immediate development.

04

Boot the Gateway Server

Start the local server. On Windows PowerShell, run npm.cmd start or npm start:

START SERVER 
npm start

Expected startup terminal output:

TERMINAL LOGS // ONLINE 
=======================================================
  GuardAgent — AI Agent Security Platform
  Server running at: http://localhost:3000
  Public Website:   http://localhost:3000/
  Security Console: http://localhost:3000/app/
=======================================================
05

Verify Health API

In another terminal tab, ping the health endpoint to verify the gateway is healthy:

CURL 
curl http://localhost:3000/api/health

Expected 200 OK Response:

JSON RESPONSE 
{
  "status": "healthy",
  "version": "1.2.0",
  "timestamp": "2026-10-24T12:00:00.000Z",
  "evaluator_engine": "deterministic-ast",
  "uptime_seconds": 42
}
06

Test Policy Evaluation

Simulate an AI bot trying to process an unauthorized $1,450 refund:

CURL // EVALUATE ACTION 
curl -X POST http://localhost:3000/api/requests/evaluate \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "agt-customer-support-01",
    "tool_name": "stripe.transfers.create",
    "action_name": "process_refund",
    "parameters": {
      "amount_usd": 1450.00,
      "account_id": "act_4412_premium"
    }
  }'

Expected Policy Result:

JSON DECISION (0.8MS) 
{
  "decision": "REQUIRE_APPROVAL",
  "risk_score": 65,
  "risk_level": "HIGH RISK",
  "latency_ms": 0.8,
  "rationale": "Safety Cap Triggered: $1,450.00 exceeds your $500 safety rule."
}
07

Troubleshooting Common Issues

Port 3000 Already in Use

Set PORT=3001 in your .env file or terminate the lingering Node process with taskkill /F /IM node.exe on Windows.

PowerShell Execution Policy Error

If running npm start throws a script execution policy error on Windows, run npm.cmd start directly.
